# Sites

Every folder in here is hosted as a site, named after the folder:

```
sites/chessr/index.html  ->  http://<phone-ip>:8080/chessr/   (shown as "chessr")
```

Add, rename or delete a folder while the server runs and the dashboard updates within a second.
If a folder has no `index.html` but has a built app in `dist/`, `build/`, `public/` or `www/`, that is served instead.
